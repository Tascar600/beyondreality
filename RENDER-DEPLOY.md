# Deploy on Render

## 1. Push to GitHub

Double-click **`PUSH-TO-GITHUB.bat`** in the project folder, or run:

```bash
git init
git branch -M main
git remote add origin https://github.com/Tascar600/beyondreality.git
git add -A
git commit -m "Beyond Reality Housing Portal"
git push -u origin main
```

## 2. Create Render service

1. Go to [Render Dashboard](https://dashboard.render.com)
2. **New +** → **Blueprint**
3. Connect GitHub account and select **`Tascar600/beyondreality`**
4. Render reads `render.yaml` and creates the web service
5. Click **Apply**

## 3. Environment variables (Render dashboard)

Set these under your service → **Environment**:

| Variable | Value |
|----------|--------|
| `NODE_ENV` | `production` |
| `JWT_SECRET` | long random string (auto-generated by render.yaml) |
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `587` |
| `SMTP_USER` | `zimhungar@gmail.com` |
| `SMTP_PASS` | your Gmail App Password |
| `SMTP_FROM` | `zimhungar@gmail.com` |

## 4. After first deploy

1. Open your Render URL (e.g. `https://beyond-reality.onrender.com`)
2. Log in: **finance** / **finance123**
3. Go to **Excel Import** → upload `COMBINED SCUSTOMER STATEMENTS_042427.xlsx` → **Replace ALL**
4. Configure email in **Reports → Email Setup**

## Notes

- **Persistent disk** (1 GB) keeps SQLite database across restarts (`render.yaml` configures this).
- **Free tier** spins down after inactivity — first visit may take 30–60 seconds to wake up.
- Finance login: `finance` / `finance123`
- Client login: first name or surname + stand number

## Manual deploy (without Blueprint)

- **Build command:** `npm run install:all && npm run build`
- **Start command:** `npm run start:prod`
- **Health check path:** `/api/health`
